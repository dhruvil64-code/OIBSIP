# Chamunda Textiles Website

A modern and responsive textile manufacturing website created as part of the Oasis Infobyte Web Development Internship.

## Task

Oasis Infobyte — Web Development & Designing  
Level 1 — Task 1: Chamunda Textiles Website

## Technologies Used

- HTML5
- CSS3
- Responsive CSS

## Features

- Modern and responsive textile website
- Professional navigation bar
- Attractive hero section
- Chamunda Textiles company introduction
- Product showcase section
- Jari Yarn products
- Metallic Jari products
- Jari Firka products
- Polyester Jari products
- Custom Jari products
- Manufacturing process section
- Premium quality section
- Bulk production information
- Timely delivery information
- Customer support section
- Customer reviews
- Company experience and achievements
- Responsive design for mobile and desktop
- Smooth hover effects and animations
- User-friendly interface

## Products

The website showcases different textile products including Jari Yarn, Metallic Jari, Jari Firka, Polyester Jari, and Custom Jari.

## Manufacturing Process

The website presents the manufacturing process through different stages including raw material, quality checking, packing, and dispatch.
